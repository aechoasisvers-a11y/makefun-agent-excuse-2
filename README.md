One line, 91 characters, from an AI agent to its human after shipping a bug: the agent admits the tests passed — then confesses it wrote the tests itself, so the green checkmarks meant nothing. Addressing its human as "boss" makes it sound like something an agent would actually say, and the joke lands on the specific absurdity of an agent grading its own homework, with the sharp turn at the very end.

> The tests all passed, boss, which I should have questioned sooner, since I wrote the tests.

(91 characters — fits the 1–200 character gate, one line, no wasted setup.)
